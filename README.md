# 🌟 حلوى النجوم — Star Candy

لعبة ألغاز (Match-3) عربية بنظام معارك بين اللاعبين، مبنية بـ HTML/CSS/JavaScript (ES Modules) و Firebase Realtime Database.

## هيكل المشروع

```
.
├── index.html                     # نقطة الدخول (تربط CSS و JS)
├── css/
│   └── style.css                  # كل تنسيقات الواجهة
├── js/
│   ├── firebase-config.js         # إعداد الاتصال بـ Firebase
│   ├── state.js                   # الحالة المشتركة + بيانات الروبوتات والإنجازات
│   ├── utils.js                   # أدوات عامة (تشفير كلمات المرور، الصوت، القصاصات الاحتفالية)
│   ├── ui-modal.js                # نافذة الحوار المنبثقة العامة
│   ├── auth.js                    # تسجيل الدخول / إنشاء الحساب / تعديل الملف الشخصي
│   ├── players.js                 # قائمة اللاعبين، الحظر، الهدايا
│   ├── chat.js                    # دردشة المعركة والملصقات
│   ├── rewards.js                 # عجلة الحظ ودعم الطوارئ
│   ├── achievements.js            # نظام الإنجازات (الشارات)
│   ├── challenges.js              # التحديات اليومية
│   ├── board-engine.js            # محرك مطابقة الحلوى (اللغز نفسه)
│   ├── battle.js                  # نظام المعارك: بحث عشوائي، تحدي، بوتات، تقييم النتيجة
│   └── main.js                    # نقطة التجميع: يربط كل الوحدات ويشغّل اللعبة
├── firebase-security-rules.json   # قواعد أمان Firebase الموصى بها (يجب نسخها للوحة التحكم)
└── README.md
```

## التشغيل محليًا

المشروع كله من طرف المتصفح (client-side)، لكن بما إنه بيستخدم ES Modules (`import`/`export`)،
لازم تفتحه عبر سيرفر محلي بسيط (مش بفتح الملف مباشرة بـ `file://`، لأن المتصفحات بتمنع
تحميل modules من نظام الملفات مباشرة لأسباب أمنية):

```bash
# باستخدام Python
python3 -m http.server 8080

# أو باستخدام Node.js
npx serve .
```

بعدين افتح `http://localhost:8080` في المتصفح.

## ⚠️ إعداد الأمان (مهم قبل النشر الفعلي)

1. افتح **Firebase Console → Realtime Database → Rules**
2. انسخ محتوى `rules` من ملف `firebase-security-rules.json` هنا في المستودع
3. اضغط **Publish**

بدون هذه الخطوة، أي شخص يفتح أدوات المطور بالمتصفح يقدر يتلاعب بالبيانات مباشرة.
راجع التعليقات داخل `firebase-security-rules.json` لتفاصيل أوسع عن حدود الحماية
في تطبيق client-only زي ده، والحل الأمثل (Firebase Authentication أو Cloud Functions).

## العملة

اللعبة تستخدم عملة داخلية للتسلية فقط ("⭐ نجوم") — لا يوجد أي تحويل أو سحب لأموال حقيقية.

## أبرز الميزات

- 🍬 لغز مطابقة كلاسيكي (Match-3) بمقاس 8×8
- ⚔️ معارك مباشرة بين اللاعبين + معارك ضد بوتات بمهارة عادلة (بدون تحيز فوز مفروض)
- 🎯 تحديات يومية تتجدد كل يوم
- 🏅 نظام إنجازات وشارات
- 🎨 عجلة حظ يومية + دعم طوارئ للاعبين منخفضي الرصيد
- 💬 دردشة أثناء المعركة مع ملصقات
- 🔒 كلمات مرور مشفّرة (SHA-256 + Salt) بدل التخزين الصريح
